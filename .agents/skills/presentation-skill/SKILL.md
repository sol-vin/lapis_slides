# Presentation Skill: Structured Deck Generation

Create clean, structured presentations from declarative source models and data.

## Core Contract

- Treat presentation manifests (`deck.yml`, `outline.json`), slide models, data, and diagrams as source of truth.
- Build deterministically with CLI commands. Do not write one-off manual monkey-patches when source templates exist.
- Keep text, charts, code snippets, and diagrams modular and editable where practical.
- Use layout grammars as a design system, not a rigid, monotonous template sequence.
- Fix source templates and rebuild until geometry, readability, placeholders, and rendered visual inspections pass.
- Enforce strict contrast, typographical hierarchy, and comfortable reading bounds.
