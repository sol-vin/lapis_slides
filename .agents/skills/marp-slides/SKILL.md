# Marp & Markdown Slide Authoring Guide

Techniques and conventions for creating high-quality slide decks directly from Markdown definitions.

## Key Principles

- **Markdown-First Philosophy**: Clear slide separation using standard horizontal rules (`---`).
- **Directives & Scoped Styling**: Use frontmatter and inline comments to control theme, paginate slides, headers, footers, and background styles.
- **Visual Composition**: Leverage multi-column containers, callout boxes, and code styling without breaking the underlying portable Markdown representation.
- **Presenter Notes Support**: Keep presenter speaking cues embedded directly within slide comments or dedicated notes blocks.
